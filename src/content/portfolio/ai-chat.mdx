<p>
	<strong>AI Chat</strong> is a lightweight, responsive chat interface designed to run LLM conversations at the edge. Utilizing Server-Sent Events (SSE) to stream text responses from Cloudflare's model registry, it provides a performant chatbot workspace with minimal load-time overhead and client-side history preservation.
</p>

<h2>Core Features</h2>
<ul>
	<li><strong>Responsive Chat Interface</strong> — Clean, mobile-friendly layout optimized for typing, reading, and viewing code blocks.</li>
	<li><strong>AI Gateway Integration</strong> — Configured to run through Cloudflare AI Gateway to enable caching, logging, analytics, and custom rate limits.</li>
	<li><strong>Local History Persistence</strong> — Stores conversation history directly on the user's browser, preventing server leaks and maintaining chat continuity across reloads.</li>
	<li><strong>Custom Prompts</strong> — Easily supports overriding the LLM's system prompt or selecting different model categories directly from the web layout.</li>
</ul>
