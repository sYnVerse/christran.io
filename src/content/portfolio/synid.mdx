<p>
	<strong>sYnID</strong> is a centralized authentication provider that acts as a universal single sign-on gateway for applications in the sYnVerse ecosystem. Deployed entirely on Cloudflare Workers, it shares active sessions across subdomains, allowing users to sign in once and access all connected services seamlessly.
</p>

<h2>Core Features</h2>
<ul>
	<li><strong>Multi-Provider Authentication</strong> — Integrates classic Email/Password credentials, Google OAuth, GitHub OAuth, and Microsoft Entra ID.</li>
	<li><strong>Account Linking</strong> — Allows users to bind multiple OAuth credentials to a single email address, preventing duplicate accounts.</li>
	<li><strong>Post-Based Central Logout</strong> — Features a secure, POST-verified logout endpoint that clears cookies across all linked client applications.</li>
	<li><strong>Security Hardening</strong> — Protects endpoints with Turnstile CAPTCHA (featuring automatic rate-limit token resets) and prevents browser predictive prefetching from accidentally executing sign-outs.</li>
</ul>
