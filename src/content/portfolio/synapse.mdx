<p>
	<strong>sYnapse</strong> is a modern, unified agentic trading gateway designed to interface with various broker APIs, enabling secure, autonomous, and low-latency algorithmic trading. Built to run on edge infrastructure, it coordinates and executes trades on both equity and futures markets while providing real-time telemetry on active positions, capital allocation, and order statuses.
</p>

<h2>Core Features</h2>
<ul>
	<li><strong>Secure Broker Gateways</strong> — Handles OAuth, session refreshes, and encrypted API keys securely at the edge.</li>
	<li><strong>Durable WebSockets</strong> — Maintains constant, low-latency socket connections to broker data streams using Cloudflare Durable Objects.</li>
	<li><strong>State Management</strong> — Logs orders, trades, and strategy metrics into a serverless SQL database (D1) for analytics.</li>
	<li><strong>Single Sign-On (SSO)</strong> — Seamless authentication integration using the shared domain's sYnID provider.</li>
	<li><strong>Strategy Backtesting</strong> — Historical backtesting engine that simulates performance, returns trades, equity curves, metrics, and visualizes indicators.</li>
</ul>

<h2>Supported Strategies</h2>
<ul>
	<li><strong>MACD Crossover (<code>macd_crossover</code>)</strong> — Computes fast/slow EMAs and a signal line, triggering signals on crossover events.</li>
	<li><strong>Donchian Channel Breakout (<code>donchian_breakout</code>)</strong> — Computes rolling high/low bounds, buying breakouts on the upper channel and selling on the lower channel.</li>
	<li><strong>Z-Score Mean Reversion (<code>zscore_reversion</code>)</strong> — Measures standard deviations from SMA to buy oversold assets (Z-Score &lt; -2.0) and sell overbought ones (Z-Score &gt; 2.0).</li>
	<li><strong>Congressional Political Trades (<code>political_trades</code>)</strong> — Automates positions based on US House and Senate STOCK Act filings, synced via S3 to SQLite/D1 to build a custom Congressional Sentiment Index (CSI).</li>
</ul>

<h2>Technical Organization</h2>
<p>
	The application repository is split into a deployable edge backend and a single-page administration UI:
</p>
<ul>
	<li><code>src/worker.ts</code>: Worker API endpoints, cron executor, and static asset serving</li>
	<li><code>src/brokers/*</code>: Broker client wrappers (Alpaca, Tradovate) and authentication managers</li>
	<li><code>web/</code>: React UI dashboard for configuration, manual order override, and strategy performance visualization</li>
</ul>
