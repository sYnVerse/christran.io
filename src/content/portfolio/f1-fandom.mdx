<p>
	<strong>F1 Wiki Automator</strong> is a comprehensive automation pipeline and dashboard that keeps the Formula 1 Wiki on Fandom updated with real-time race data. By pulling from open F1 telemetry endpoints, scraping session articles, and parsing session times, it formats, compiles, and deploys MediaWiki wikitext templates automatically at the conclusion of every Grand Prix weekend session.
</p>

<h2>Core Features</h2>
<ul>
	<li><strong>LLM-Powered Section Reports</strong> — Automatically crawls F1.com session articles and uses Llama 3 (Cloudflare Workers AI), Google Gemini, or OpenAI with automatic failovers to draft factual, encyclopedia-style reports for GP sections without overwriting human edits.</li>
	<li><strong>Dynamic Infobox Updating</strong> — Parses and populates race infoboxes (`Infobox_Race` / `Infobox Sprint Race`) with pole times, podium finishers, fastest laps, and sprint standings as each session concludes.</li>
	<li><strong>21 Career Stats Templates</strong> — Computes cumulative stats (Championships, Wins, Podiums, Poles, Entries, Laps Led, etc.) by combining historical baselines with active season results.</li>
	<li><strong>Practice & Test Driver Automation</strong> — Scrapes raw practice results from Formula1.com, handles time differentials, and dynamically appends rookie test drivers appearing in FP1 to the wiki's Entry List.</li>
	<li><strong>Granular KV Sync Flags</strong> — Leverages per-target Cloudflare KV sync states (for each section, career template, and standings template) to isolate retry behavior and prevent a single failure from blocking other updates.</li>
	<li><strong>CodeQL-Safe Wikitext Parsing</strong> — Avoids ReDoS vulnerabilities by replacing polynomial regular expressions with custom line-by-line parsing algorithms (`wikitext-parse.ts`) for MediaWiki templates.</li>
	<li><strong>Operational Reporting Dashboard</strong> — Integrates with the Resend API to deliver daily status emails (at 6 AM PST) listing API quotas, successes, failures, and warnings like crawling issues or unresolved test driver flags, managed via an interactive, F1-themed web control panel.</li>
</ul>
