<p>
	<strong>sYntinel</strong> is a real-time monitoring dashboard featuring an interactive 3D WebGL globe. It aggregates status information from major infrastructure providers and displays them as geographically positioned, color-coded telemetry columns. This visual cockpit allows administrators to identify global service disruptions and regional connectivity issues instantly.
</p>

<h2>Core Features</h2>

- <strong>Interactive 3D Globe</strong> — Color-coded columns show service status at a glance:
  - <span style={{color: '#ff5f56', fontWeight: 'bold'}}>Down</span> — Red columns, high altitude
  - <span style={{color: '#ffbd2e', fontWeight: 'bold'}}>Degraded</span> — Orange columns, medium altitude
  - <span style={{color: '#27c93f', fontWeight: 'bold'}}>Operational</span> — Green columns, low altitude
- <strong>System Monitor Dashboard</strong> — Includes radar pulse status indicators, 24-hour uptime timelines, latency metrics, and a live incident log feed.
- <strong>Outage Disaster Simulator</strong> — Admins can trigger simulated disaster scenarios to test visualization grids, including:
  - *Solar Flare* (Global collapse of all monitored services)
  - *DNS Backbone Collapsed* (Widespread degraded status)
  - *AWS Cloud Core Outage* (Regional outage targeting North American/European zones)
- <strong>Focus Mode</strong> — Hides sidebar controls and expands the system monitor dashboard into a full-screen, distraction-free environment ideal for server room displays.
