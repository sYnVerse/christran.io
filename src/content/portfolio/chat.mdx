<p>
	<strong>Chat</strong> is a real-time, multi-room WebSocket communication application. Built on Cloudflare Workers and utilizing Durable Objects, it supports persistent, synchronized, and low-latency chat sessions between multiple concurrent users within custom-defined rooms.
</p>

<h2>Core Features</h2>
<ul>
	<li><strong>Multi-Room Separation</strong> — Dynamic room generation based on URL slug paths. Users in the same URL route are grouped into a dedicated Durable Object instance.</li>
	<li><strong>WebSocket Broadcasts</strong> — Messages sent by a user are instantly broadcast to all active connections in that room, ensuring real-time text delivery.</li>
	<li><strong>Automatic History Load</strong> — When a new user opens a room, the Durable Object queries its local SQL table to retrieve and render the chat room's message history.</li>
	<li><strong>PartyServer Simplicity</strong> — Leverages the PartyKit/PartyServer API to streamline socket connections and event routing without complex state management code.</li>
</ul>
