<p>
	<strong>sYnX</strong> is a fast, collaborative task management application designed to organize and track personal and professional responsibilities. Built as a serverless static asset application utilizing the Remix framework, it provides an intuitive user interface with robust offline-first caching and Cloudflare D1 database persistence.
</p>

<h2>Core Features</h2>
<ul>
	<li><strong>Collaborative Sharing</strong> — Share task lists as Private, View-Only, or Collaborative for team coordination.</li>
	<li><strong>Nested Subtasks</strong> — Break down tasks into single-level subtask checklists.</li>
	<li><strong>Recurring Tasks</strong> — Automate repeating chores with Daily, Weekly, and Monthly recurrence periods.</li>
	<li><strong>Search & Sorting Options</strong> — Instantly filter tasks and sort by Priority, Due Date, Alphabetical, or Date Created.</li>
	<li><strong>Theme Customizer</strong> — Toggle between Midnight Indigo, Emerald Forest, Sunset Rose, and Cyberpunk Neon dark themes.</li>
	<li><strong>Smart Web Notifications</strong> — Local browser pushes and synced email/SMS/Discord notification integrations for task reminders.</li>
</ul>
