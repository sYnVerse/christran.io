<p>
	<strong>sYnX</strong> is a fast, responsive task management application designed to organize and track personal and professional responsibilities. Built as a serverless static asset application utilizing the Remix framework, it provides an intuitive user interface with robust offline-first caching and KV-backed server persistence.
</p>

<h2>Core Features</h2>
<ul>
	<li><strong>Task Organization</strong> — Add, remove, edit, and categorize items based on priority levels and due dates.</li>
	<li><strong>Remix Routing</strong> — Utilizes Remix's nested routers to update specific sections of the dashboard instantly without full page refreshes.</li>
	<li><strong>Workers KV Persistence</strong> — High-speed reads and writes to global KV storage ensure task states load near-instantly regardless of location.</li>
	<li><strong>Cloudflare Assets</strong> — Deploys static assets globally, serving client files directly from Cloudflare's edge CDN.</li>
</ul>
