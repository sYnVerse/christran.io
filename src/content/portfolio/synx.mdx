<p>
	<strong>sYnX</strong> is a fast, collaborative to-do list app for organizing and tracking personal and professional tasks on the web and on Android. The web app is built with React Router 8 and runs on Cloudflare Workers with a Cloudflare D1 database. The Android app is built with Expo and React Native and uses the same account and data through the web app's REST API. Sign-in goes through <a href="/portfolio/synid">sYnID</a>, the sYnVerse single sign-on server.
</p>

<p>
	sYnX is open source under the GNU AGPL-3.0 license. The full source is on <a href="https://github.com/sYnVerse/sYnX" target="_blank" rel="noopener noreferrer">GitHub</a>.
</p>

<h2>Core Features</h2>
<ul>
	<li><strong>Collaborative Sharing & Creator Deletes</strong> — Share task lists as Private, View-Only, or Collaborative. Lists opened from someone else's link appear under "Shared with me" with the owner's display name, and emails are never shown. On Collaborative lists, collaborators can delete tasks they added themselves immediately without waiting for owner approval, while deleting tasks added by others still routes through owner approval queues.</li>
	<li><strong>Activity Log</strong> — Shared lists keep an owner-only Activity log of who added, edited, completed, or deleted tasks and who requested deletes. Entries are removed automatically after 90 days.</li>
	<li><strong>Completed Section</strong> — Completed tasks and subtasks automatically move into a collapsible "Completed (N)" section at the bottom of lists and subtask lists on both web and mobile, keeping workflows tidy while preserving one-tap unchecking and restoration.</li>
	<li><strong>Nested Subtasks & Dedicated Editing</strong> — Break tasks down into subtasks nested under their parent task. On mobile, a dedicated subtask editing modal provides pencil actions, multiline title text wrapping, and compact duration indicators.</li>
	<li><strong>Priorities, Durations & Category Emojis</strong> — Assign priority levels with visual colored left stripes on mobile, optional task durations with narrow-screen responsive pickers, and category tags displaying preset emoji indicators (🛒 Shopping, 🎬 Movies, 📚 Study, ✈️ Travel, etc.) across web and mobile, with support for clearing back to None.</li>
	<li><strong>Reminders & Recurring Tasks</strong> — Set reminders with quick presets or a custom date and time picker (with distinct reminder date and time indicators on mobile task cards), and repeat tasks Daily, Weekly, or Monthly. Repeating tasks preserve their local time in your home time zone across daylight saving changes.</li>
	<li><strong>Calendar View & Device Sync</strong> — View tasks on an interactive calendar next to the list view. On the web, drag unscheduled tasks onto any day; on mobile, synchronize reminders directly to device calendars with interactive permission prompt detection.</li>
	<li><strong>Search & Sorting Options</strong> — Search tasks and subtasks with isolated matching subtasks and highlighted query terms. Filter by All, Active, or Done, and sort by Reminder Time (with priority fallback), Date Created, or Name, remembered per list.</li>
	<li><strong>Streaming Performance & Instant Navigation</strong> — The web app utilizes React Router deferred loaders to render task lists instantly while streaming activity logs, delete queues, and profile avatars via Suspense. Sidebar list switching leverages client-side prefetching (<code>Link prefetch="intent"</code>) for instantaneous transitions without full-page reloads.</li>
	<li><strong>Over-The-Air (OTA) Mobile Updates</strong> — The mobile app receives rapid over-the-air JavaScript and asset updates through <code>expo-updates</code>. The EAS CI/CD pipeline calculates runtime fingerprints to auto-publish OTA updates when native code is untouched, and only builds new preview APKs when native dependencies change.</li>
	<li><strong>Multi-Channel Notifications</strong> — An every-minute cron trigger sends due reminders by email, text message (supporting all major carriers), Discord webhook, and push notifications to phones, with real-time browser notifications while the web app is open.</li>
	<li><strong>Single Sign-On & Guest Mode</strong> — Sign in once with sYnID, with sessions that renew seamlessly in the background and support OAuth profiles (Google, GitHub, Microsoft). Without signing in, guest mode stores lists in local browser storage and seamlessly migrates them upon authentication. Guests can view shared lists in read-only mode and sign in to collaborate.</li>
	<li><strong>Android App & Interactive Widgets</strong> — Native Android app featuring Tasks, Calendar, Lists, and Settings screens, plus three home screen widgets. The Pinned List widget allows switching the active list directly from the home screen widget and adheres to the list's custom task sort order.</li>
	<li><strong>Theme Customizer</strong> — Choose between Midnight Indigo, Emerald Forest, Sunset Rose, Cyberpunk Neon, and Light Pastel themes on the web, and light, dark, or system themes on Android.</li>
</ul>
