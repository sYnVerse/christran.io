<p>
	<strong>sYnFi</strong> is a modern, mobile-first personal and family finance application in the sYnVerse ecosystem designed for tracking peer and family loans, generating formal promissory agreements, and managing group vacation travel expenses with automated debt simplification. Built with React Native and Expo for iOS, Android, and Web, sYnFi runs on a 100% serverless Cloudflare stack (Workers, D1 SQLite database, and Static Assets). Authentication is unified across the ecosystem through <a href="/portfolio/synid">sYnID</a> Single Sign-On.
</p>

<p>
	sYnFi is developed as a private, proprietary personal finance application within the sYnVerse ecosystem, purpose-built for secure family lending, peer agreements, and collaborative travel ledgers.
</p>

<h2>Core Features</h2>
<ul>
	<li><strong>Family & Peer Loan Management</strong> — Manage loans from either perspective: "Money I've Lent" (Lender) or "Money I've Borrowed" (Borrower), with real-time principal balance tracking, payment progress rings, and remaining installment counters.</li>
	<li><strong>0% Family Courtesy Rate & Custom APR</strong> — Standard zero-interest family loan support with exact-cent penny distribution to eliminate fractional rounding errors. Also supports customizable APR amortization terms with monthly, bi-weekly, or lump-sum repayments extending up to 72 months.</li>
	<li><strong>Promissory Agreement Generator</strong> — Create formal yet respectful promissory agreements tailored for family and friends. Borrowers and lenders can review terms, interest details, and payment schedules, then digitally acknowledge the agreement directly in the app.</li>
	<li><strong>Immutable Payment Ledger</strong> — Record repayments via Zelle, Venmo, Bank Transfer, Cash, or Check. Includes custom transaction date pickers, notes, and real-time principal recalculation backed by an immutable audit trail.</li>
	<li><strong>Vacation Trip Ledger (v2.0)</strong> — A dedicated group travel expense tracker for vacations and group outings. Create trips, invite travel companions, record split expenses across categories (Flights, Lodging, Dining, Transit, Activities, Shopping), and view real-time net balances.</li>
	<li><strong>Smart Settle Debt Simplification</strong> — Built-in greedy minimal cash-flow engine that minimizes cross-debts among travelers into the smallest possible number of direct settlement transfers.</li>
	<li><strong>Plaid Bank Linking (Dual-Mode)</strong> — Seamless account linking with a built-in mock sandbox engine for immediate testing without API keys, plus seamless developer tier integration for linking real institutions with masked account numbers and encrypted tokens.</li>
	<li><strong>Glassmorphic Multi-Module Navigation</strong> — Universal floating glassmorphic tab bar with haptic feedback, dark obsidian and warm cream light themes, and an interactive Dashboard module switcher pill (<code>[ 🤝 Family Loans | ✈️ Vacation Trips ]</code>).</li>
	<li><strong>Over-The-Air (OTA) Updates</strong> — Native mobile improvements and fixes deploy over-the-air through <code>expo-updates</code>. The EAS workflow computes native runtime fingerprints, automatically deploying OTA updates for JavaScript changes and building preview APKs only when native binary dependencies change.</li>
	<li><strong>Single Sign-On (sYnID)</strong> — Seamless authentication powered by sYnID OpenAuth with PKCE S256, strict audience (<code>aud</code>) validation to prevent cross-app token reuse, and hardware-backed credential storage via iOS Keychain and Android Keystore.</li>
	<li><strong>Automated E2E Testing</strong> — Comprehensive Playwright automated test suite verifying critical loan calculation workflows, trip ledger splits, and responsive viewports across desktop and mobile.</li>
</ul>
