<p>
	<strong>sYnTools</strong> is Chris Tran's self-hosted fork of <a href="https://github.com/CorentinTh/it-tools" target="_blank" rel="noopener noreferrer">CorentinTh/it-tools</a> (via <a href="https://github.com/sharevb/it-tools" target="_blank" rel="noopener noreferrer">sharevb/it-tools</a> <code>chore/all-my-stuffs</code>) — a browser-based toolbox of converters, crypto helpers, network utilities, and more. Hosted at <a href="https://tools.christran.io" target="_blank" rel="noopener noreferrer">tools.christran.io</a> and maintained on the <code>sYn-local-config</code> branch with periodic upstream syncs.
</p>

<h2>Customizations</h2>
<ul>
	<li><strong>Full sYnTools Branding</strong> — Sidebar, document title, PWA manifest, Open Graph tags, and icons aligned with the christran.io identity (<code>#7B9EFF</code> accent, <code>#0B1021</code> navy).</li>
	<li><strong>About & Splash</strong> — Custom About page and splash screen with the tagline <em>Engineering. Security. Automation.</em> matching the main site's look.</li>
	<li><strong>Privacy Defaults</strong> — All upstream analytics and tracking (including Plausible) removed; tools process inputs in the browser.</li>
	<li><strong>Upstream Sync</strong> — Periodically rebased against sharevb/it-tools so new utilities and fixes land without losing local branding and hardening.</li>
</ul>
